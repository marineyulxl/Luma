保存

写下正文或导入资料后，直接保存。无需先选择目录、标签、学习状态或思考脉络。

入口保存位置如何处理保存后的结果
首页随手记录位置默认留空，可主动指定生成一条有稳定 ID 的记录，保留正文、时间和来源。默认私有，立即出现在「全部记录」，可阅读和搜索。
目录内新建沿用当前空间或分类
文件、网页、AI 对话导入可暂不指定位置，保留导入来源和批次

全部记录是所有内容的时间视图。未指定位置也能长期使用；「待整理」可作为筛选视图，整理按需进行。

归类

归类用于安排内容的位置，方便按目录浏览。

位置 · 一个主要归属

界面提供一个「位置」入口，搜索或选择完整路径，例如「技术研究 / Python」。允许只选空间，也允许留空。

空间与分类由同一个选择器承接。移动位置只修改归属，原文和 ID 保留。

标签 · 多个横向标记

例如「AI」「职业」「产品」。一条记录可以有多个标签，从不同主题筛选出同一份内容。

标签可随时补充。类型和学习状态也放在可选属性中，保存时无需逐项填写。

批量设置位置与标签的具体交互待设计。

关联

关联表达记录之间的关系，以及多条记录共同涉及的问题。

形式连接什么如何建立
记录链接一条记录与另一条记录，例如函数笔记与接口故障复盘手动引用或添加关系，支持查看反向引用
思考脉络围绕同一长期问题的多条记录，可跨目录和时间用户主动创建，或 AI 提议后由用户确认。新记录先进入「可能相关」，确认后加入。
关联图已有主题、记录和关系把已有连接画出来，节点打开原文，连线说明关系。图本身不创建额外副本。

一条记录可以加入多个脉络。脉络先展示有原文依据的梳理，再提供关联图和时间线。无依据的联系保留为候选。

找回与使用

找回知识

按关键词搜索，或沿目录、标签、已有链接打开原文。核对背景和来源后，用于学习、项目、写作或解决问题。

回看思考

进入思考脉络，查看不同时间的表达、相关经历和观点差异，辅助当前判断。推测与原文表达分别呈现。

实践后可以补充原记录，或新建一次经验、复盘、选择及结果，再关联到原记录或脉络。

同一份内容的不同入口

记录「学习 AI 是为了换工作，还是为了独立做产品？」

  • 保存后自动出现在当天的「全部记录」。
  • 可选位置「技术研究 / AI」，从目录找到。
  • 可加标签「职业」「产品」，从标签找到。
  • 确认加入「我希望怎样发展职业？」后，从脉络找到。

这些入口打开同一个 ID 的原文。修改原文后，各入口引用同一份更新后的内容。

AI 理解与长期记忆

AI 按内容权限参与检索、分析和关联建议。AI 对话需保留发言角色，区分用户表达、引用、AI 建议与用户明确认可。

长期记忆是从记录中提取的个人上下文。默认允许 AI 对话参与理解和候选提取，候选由用户确认后生效，支持查看来源、纠正与删除。

脉络梳理发现有意义的变化时生成候选新版，标明差异和证据，经用户接受后更新当前版本，并保留历史。

Agent 可在授权范围内利用这些材料完成研究、整理或规划任务，重要写入与执行另行控制权限。

发布、备份与删除

操作结果
主动发布预览并确认后，选定内容及附件进入 Explore。已发布内容保存后同步更新，撤回停止公开访问并保留私人原文。
导出与备份Markdown 用于阅读和迁移，完整备份用于恢复内容、组织结构和关系。V1.0 恢复到空白工作区。
归档与删除归档减少日常干扰。删除进入回收站，恢复时尽量保留原位置；位置失效时仍可从全部记录找到。永久删除需要确认。

交付范围

V1.0 优先保存、编辑、目录、搜索、手动关联、发布和备份。AI 发现脉络、长期记忆提取与梳理版本属于后续能力。本文说明产品逻辑，具体交付阶段以 PRD 为准。
