记录、组织与使用

实线表示直接使用路径，虚线表示可选操作 · 点击节点查看说明

保存之后就是笔记

学习笔记、AI 对话、生活随记、人生思考和工作记录都可以保存。记录保留正文、时间和来源，允许直接阅读、编辑与搜索。

首页可不选位置。目录内新建沿用当前位置。导入保留批次及失败反馈。取消收集箱，记录直接保存。系统建议的位置与标签集中展示，确认后应用，支持批量确认、修改或忽略。

位置、标签与脉络

位置提供一个主要目录归属，标签提供多个筛选入口。记录链接连接具体原文，思考脉络连接围绕长期问题的多条记录。

同一条记录可以同时出现在时间、目录、标签和脉络中，修改的是同一份原文。

不同内容怎样使用

内容直接使用按需继续
学习笔记回看解释、例子和自己的理解实践后补充理解，关联项目经验
AI 对话找到讨论过程与有价值的回答选取需要的片段整理成笔记，保留原对话依据
生活随记按时间回看当时发生的事和感受连接后续经历或相关思考
人生思考回看问题、观点与当时的背景在脉络中比较不同时间的表达
工作记录找回方案、处理过程、判断依据按需要整理可复用方法，记录实际结果

知识与经验的复用

遇到问题 → 找回材料 → 理解并使用 → 有新发现时补充或新建 → 下次使用更新后的材料

可重复执行的方法适合整理成操作步骤。知识解释、个人感受和未解决的问题可以采用其他形式。

思考的持续发展

记录想法与经历 → 确认相关联系 → 回看思考脉络 → 辅助当前判断 → 新经历继续补充

脉络先展示有引用的梳理，再提供原文、关联图与时间线。相似主题只作为联系线索，判断变化需要证据。

AI 与 Agent 的参与方式

能力作用确认与依据
找材料根据当前问题检索记录遵循来源与内容权限，返回原文依据
串起思考提出主题、候选关联与脉络梳理主题与新成员经确认；梳理标明来源及推断
形成长期记忆提取可持续使用的个人上下文候选经确认生效，可纠正、删除并追溯来源
提出建议结合历史材料辅助当前判断区分原始表达、AI 推测和建议
完成任务规划步骤、调用工具，交付研究或工作结果执行遵循授权，重要写入、发布和删除有明确控制

能力逐步建设。默认允许导入 AI 对话参与理解与候选记忆提取，长期记忆经确认生效。允许按来源、按内容收紧权限。AI 对话保留角色，用户引用与 AI 回答都不能自动视为个人观点。

脉络出现有意义变化时，生成带证据与差异的候选新版。接受后更新当前梳理并保留历史。原始记录与 AI 解释分别保留。

发布与数据保护

发布前预览并确认。已发布内容保存后同步更新，撤回停止公开访问并保留私人原文。

Markdown 用于阅读和迁移，完整备份用于恢复。归档减少干扰，删除进入回收站，永久删除需确认。
