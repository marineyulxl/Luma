# 灵脑 Studio · DESIGN

本文是 [Studio 原型](../../prototypes/studio/index.html) 的设计总览，涵盖全部 14 个现行页面。页面行为以原型源码为准，产品目标与交付约束见 [PRD](../product/PRD.md)。归档原型保留作历史参考。

后续 UI 可以自由设计。以「页面与交互」为功能清单，确保用户能看到必要内容、找到操作入口，并收到清晰的结果反馈。布局、配色、尺寸和动效可以按页面用途重新设计。涉及功能取舍、操作结果或权限边界的变化，需要同步更新对应产品文档。

## 产品体验

Studio 是所有者的私人工作室。首页呈现最近保存的思考与经历，快速记录、搜索和知识目录提供随时可达的入口。思考脉络用于回看跨时间的记录，知识空间用于按目录组织内容，学习中心用于追踪掌握状态。三个视角可以引用同一份记录。

| 任务 | 路径 |
| --- | --- |
| 随手记录 | 首页「记录此刻」→ 选择类型、填写正文 → 保存到收集箱 → 需要时整理归类 |
| 写一篇笔记 | 知识空间 → 进入空间或分类 → 新建笔记 → 编辑标题和正文 → 自动或手动保存 |
| 找回内容 | 搜索 → 输入关键词或设置筛选 → 进入原文 |
| 回看一条思考 | 思考脉络 → 展开主题 → 阅读梳理与引用 → 查看关联图和时间线 → 打开原文 |
| 导入、整理与备份 | 导入中心 → 查看结果 → 收集箱整理 → 设置中的数据管理 |
| 删除与恢复 | 编辑页或列表移入回收站 → 恢复或确认永久删除 |

## 原型导航与布局参考

桌面使用固定左栏与可滚动主区。左栏从上到下为品牌、搜索、新建记录、首页、收集箱、知识空间、思考脉络、导入中心、学习中心、空间分类树、设置与回收站。顶部显示 Studio、当前路径及语言按钮。空间树展开状态保存在当前会话。

| 屏宽 | 原型布局 |
| --- | --- |
| 大于 1250px | 252px 左栏。主内容按页面使用阅读列、列表或网格。 |
| 701–1250px | 240px 左栏。1050px 及以下空间和导入网格、空间详情布局改为单列，编辑属性栏收窄。 |
| 700px 及以下 | 底部固定导航为首页、搜索、收集箱、更多。更多向上展开工作室目录。当前快捷页有选中底色。内容区域为底栏预留空间，顶部仍可切换语言。首页记录单列，编辑属性移到正文下方。 |

首页自然滚动，展开快记仍显示页头和最近记录。移动端验收重点是浏览、搜索、快记、底栏切换和返回，特别检查软键盘打开时的操作和底部安全区。

## 页面与交互

| 页面 | 现有结构与交互 |
| --- | --- |
| [登录](../../prototypes/studio/login.html) | 品牌、账号、密码、登录反馈与演示账号提示。完成登录后进入 Studio 或返回目标页。单所有者原型，无公开注册。 |
| [首页「此刻」](../../prototypes/studio/index.html) | 日期、标题、可展开快记、最多六条最近更新记录和搜索入口。快记支持四类内容，标题可省略，自动取正文首行。保存前要求正文非空，成功后清空并收起。最近记录以自适应卡片网格呈现，包含类型、更新时间、标题与两行以内摘要，点击打开编辑页。空库有记录引导。 |
| [收集箱](../../prototypes/studio/inbox.html) | 待整理和已归档页签、条目计数与列表。由快记和导入进入待整理，查看详情后可完成整理。归档影响整理状态，与公开状态分开。 |
| [知识空间](../../prototypes/studio/spaces.html) | 空间卡片展示名称、简介、内容数和分类数。支持新建及管理空间。 |
| [空间详情](../../prototypes/studio/space.html) | 分类树支持多级分类、全部内容和未分类视图，选中分类可浏览子分类内容。在当前空间或分类新建笔记，直接进入编辑。支持分类管理、内容列表和分页。 |
| [笔记编辑](../../prototypes/studio/editor.html) | 标题、正文、编辑模式、格式工具栏、保存状态、整理提示与属性栏。支持可视化、Markdown 和预览。属性区管理类型、空间、分类、标签、学习状态、来源、附件、关联及发布。Markdown 中输入 `[[` 可选目标并建立关联。可以预览公开效果、确认发布或撤回，也可以移入回收站。 |
| [搜索](../../prototypes/studio/search.html) | 标题与正文关键词搜索，按空间、分类、内容类型、标签和更新时间筛选。支持相关度或最近更新排序、高亮、结果计数、分页和空结果引导。搜索范围包含收集箱和已归档内容。 |
| [思考脉络](../../prototypes/studio/threads.html) | 当前是一条可展开的手工示例。展开先看带原文入口的梳理，再看关联图，最后浏览原始记录时间线。中心问题连接「梳理产品方向」与「补充实施节奏」两条记录，节点可点击。已有记录关联独立说明，缺失或已删除记录不生成节点。 |
| [导入中心](../../prototypes/studio/imports.html) | 文件选择或拖拽、网页链接与手填摘要、ChatGPT 导出 JSON 预览勾选。文本文件读正文，DOCX、PDF 和图片按原型能力记录附件信息。导入后进入私有收集箱。批次中显示成功、部分成功、失败和跳过及原因。 |
| [学习中心](../../prototypes/studio/learning.html) | 按全部、待学习、学习中、已理解、能应用浏览内容。学习状态由用户维护。 |
| [账户设置](../../prototypes/studio/settings.html) | 所有者账号、显示名称和角色，提供修改密码和退出登录。设置区另有外观与数据管理页签。 |
| [外观](../../prototypes/studio/appearance.html) | 暖白与清白底色、灰紫等强调色预设、预览和恢复默认。偏好保存在当前浏览器。 |
| [数据管理](../../prototypes/studio/data.html) | 多选导出 Markdown，可附带 YAML 元数据。可生成 JSON 备份、查看清单、校验并确认恢复。恢复面向空白工作区。附带演示和清理工具，备份中的附件为元数据。 |
| [回收站](../../prototypes/studio/trash.html) | 展示删除时间和预计恢复位置。原位置失效时回到收集箱。支持恢复、永久删除及清空，破坏性动作需要确认。 |

## 控件、状态与反馈

- 主按钮用于保存、登录、确认等主要操作。次要动作使用描边或文本按钮，危险动作用独立色及确认对话框。搜索结果、卡片和关联节点保持可点击。
- 内容类型选择器用自定义浮层，选中项有对勾。支持方向键、回车、Esc 和点击外部关闭。搜索与属性表单仍有原生选择器。
- 原型用提示条、行内错误、弹窗及通知反馈结果。保存显示待保存、保存中、成功和失败状态。离开有未保存修改的页面时提示确认。删除、恢复和导入分别反馈操作结果。
- 快记支持 Ctrl/⌘＋Enter，完整编辑器支持 Ctrl/⌘＋S，共享壳支持 Ctrl/⌘＋K 搜索。主要操作须有可见键盘焦点，图标按钮须有名称。
- 最近记录仅当前卡片悬停时上移 2px，显示边框和轻微阴影。减少动态效果时保留静态反馈。
- 可视化模式在原型中从 CDN 加载 Tiptap，将正文保存为 Markdown。加载失败时可继续使用 Markdown。旧内容不能无损转换时使用 Markdown 源码模式。关联选择器目前位于源码模式。

## Studio 设计系统

这套清冷主题是下一版 UI 的默认起点。色值、尺寸与动效可以在实屏评审后调整。实际运行的原型样式见 [共享 CSS](../../prototypes/studio/assets/css/studio.css)。

### 1. 品牌与设计理念

主题名为「清白 · Studio」。气质清静、清晰、克制，以冷白阅读面、淡蓝灰导航和石墨色文字组织信息。用少量靛蓝标出当前选中项、主要操作与键盘焦点。首页优先让用户读到自己的记录，长文编辑留出连续的阅读空间。

### 2. 色彩系统

| Token | HEX | 用途 |
| --- | --- | --- |
| `surface` | `#F8FAFC` | 主工作区冷白底 |
| `surface-dim` | `#EDF1F6` | 侧栏、底栏与次级导航区域 |
| `surface-container-lowest` | `#FFFFFF` | 菜单、弹窗及需要区分的卡片 |
| `surface-container-low` | `#F0F3F8` | 悬停背景和辅助区域 |
| `surface-container-high` | `#E2E8F1` | 禁用控件背景与骨架 |
| `primary` | `#495C91` | 主按钮、链接、键盘焦点 |
| `primary-hover` | `#3A4A79` | 主按钮悬停背景 |
| `primary-container` | `#E5EBFA` | 导航选中底、选中菜单项 |
| `on-primary` | `#FFFFFF` | 主按钮文字与图标 |
| `on-primary-container` | `#334472` | 选中项文字与图标 |
| `text-primary` | `#202936` | 标题与正文 |
| `text-secondary` | `#526075` | 摘要、日期、辅助说明 |
| `text-tertiary` | `#5F6D81` | 占位符、快捷键和次级元数据 |
| `border-subtle` | `#E0E6EF` | 分隔线及卡片轻边框 |
| `border-strong` | `#7B899D` | 需要清楚辨认的控件轮廓 |

| 状态 | 前景 | 背景 | 用途 |
| --- | --- | --- | --- |
| `success` | `#246348` | `#E5F3EC` | 已保存、导入成功 |
| `warning` | `#815314` | `#FFF2D8` | 待整理、部分成功、需要留意 |
| `danger` | `#A1283C` | `#FCE8ED` | 删除、输入错误、保存或导入失败 |

状态同时显示文字或图标。浅色分隔线用于分组，需要凭边框辨认的输入框使用较深轮廓。

### 3. 文字排版

界面使用系统无衬线字体，中文回退可用 PingFang SC、Microsoft YaHei。代码使用 ui-monospace、SFMono-Regular、Consolas 或系统等宽字体。

| 层级 | 字号 | 行高 | 字重 | 场景 |
| --- | --- | --- | --- | --- |
| `display` | 28–32px | 1.25 | 600 | 首页、思考脉络主题 |
| `h1` | 22–24px | 1.3 | 600 | 笔记、知识空间标题 |
| `h2` | 18–20px | 1.4 | 600 | 页面区块标题 |
| `record-title` | 17px | 1.5 | 600 | 最近记录标题 |
| `body-lg` | 16px | 1.75 | 400 | 正文、编辑区 |
| `body-md` | 14px | 1.5 | 400–500 | 主导航、表单、摘要 |
| `caption` | 12–13px | 1.4 | 400–500 | 日期、标签、状态与子分类 |

### 4. 间距与布局

以 4px 为基准。常用间距为 4、8、12、16、24、32 和 48px，分别用于紧邻元素、图标与文字、控件内距、列表与卡片、面板及章节。桌面左侧目录延续 252px、较窄桌面 240px 的参考值，主导航以 36px 行高起步。移动端底栏适配安全区，主要触控目标建议至少 44px。

首页按自然顺序展示快记和最近记录，展开后保留其他内容。宽屏记录可以使用网格，窄屏转单列。编辑页先保障正文宽度，再安排属性与关联。

### 5. 圆角与阴影

小标签和快捷键用 4px 圆角，按钮、输入与下拉菜单用 8px，卡片和对话框用 12px。头像及药丸标签可用全圆角。普通卡片靠细边框划分，浮层用阴影表明层级。

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `shadow-sm` | `0 1px 2px rgba(32, 41, 54, .06)` | 需要轻微层次的卡片 |
| `shadow-hover` | `0 4px 12px rgba(73, 92, 145, .12)` | 当前悬停的可点卡片 |
| `shadow-dropdown` | `0 8px 24px rgba(32, 41, 54, .16)` | 菜单、搜索浮层 |

### 6. 组件样式

| 组件 | 默认与尺寸 | 交互状态 |
| --- | --- | --- |
| 主按钮 | 靛蓝底、白字。桌面参考高 36px、圆角 8px。 | 悬停加深，提交中保留动作反馈，禁用状态保留可辨识文字。 |
| 次要按钮与输入 | 透明或白底，轮廓与页面分组相协调。常规输入参考高 40px，同排控件对齐。 | 悬停加底色。错误用边框和行内文字共同标记。 |
| 导航与选择器 | 默认低对比背景，当前页用淡靛蓝底和深靛蓝字。 | 下拉选中项保留对勾。悬停与选中应能区分。 |
| 记录卡片 | 标题、摘要、时间优先。卡片可用冷白或纯白底。 | 可选轻微上移 2px，附近卡片保持静止。启用减少动态效果时保留静态反馈。 |
| 键盘焦点 | 参考 2px 靛蓝外描边，外扩 2px。 | 焦点在菜单、卡片和表单内保持清晰。 |
| 弹窗与反馈 | 使用统一标题、正文和操作区。 | 保存、失败及删除等结果有明确文字。确认按钮说明动作及影响。 |

## 多语言与内容来源

顶部中英文切换将偏好保存在当前浏览器。公共导航、首页和搜索已经覆盖主要界面文案，其余页面正文、状态、对话框与辅助文案尚需翻译。用户内容、空间名、标签和引用保留原文。语言切换会刷新页面，未保存编辑走离开确认。

正文、记录类型、整理、学习和发布状态各自独立。来源可来自手动记录、文件、网页或 AI 对话。导入默认私有，发布与撤回是独立操作。原型公开预览用于验证文案和操作边界，Explore 公开站目前没有现行页面。

## 原型边界与后续设计

- 原型数据和演示认证依赖浏览器存储。备份恢复、文件导入、发布状态只体现原型能力。正式认证、附件存储和公网访问需另行实现。
- 思考脉络示例用于验证「梳理 → 引用 → 关联图 → 时间线」。主题创建、候选关联确认、长期记忆与版本比较尚未实现。
- 后续沿用自由记录、AI 提出候选、用户确认的方式。梳理保留证据与历史。新版确认后成为当前解释，原始记录保留。具体阶段和权限规则见 [PRD](../product/PRD.md)。
- 待实屏核验桌面及手机宽度、英语长文案、触控与键盘导航、Tiptap 联网及降级、快记保存、打开原文和恢复数据。
