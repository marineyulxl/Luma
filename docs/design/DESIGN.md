# 灵脑 Studio · DESIGN

本文说明 Studio 的页面职责、交互和视觉参考，功能范围与验收依据 [PRD](../product/PRD.md)。[Studio 原型](../../prototypes/studio/index.html) 用于查看现有界面，具体差异见下节。

后续 UI 可以自由设计。以「页面与交互」为功能清单，确保用户能看到必要内容、找到操作入口，并收到清晰的结果反馈。布局、配色、尺寸和动效可以按页面用途重新设计。涉及功能取舍、操作结果或权限边界的变化，需要同步更新对应产品文档。

## 正式规则与原型差异

产品规则只在 [PRD](../product/PRD.md#记录与组织) 维护。下文任务路径与页面职责按正式规则维护；主题色值和布局尺寸为原型参考，后续实屏设计时核定。

- 正式产品取消收集箱，保存直接进入全部记录；原型仍保留 inbox 等旧入口。
- 首页采用自然滚动。旧原型仍有桌面一屏约束，需要在后续界面修订中移除。
- V1.0 支持人工创建思考主题、成员管理和时间线；AI 脉络发现、梳理与记忆属于后续阶段。原型目前只有手工示例，人工主题与成员操作尚未实现。
- 原型暖白默认色与后续清冷偏好存在历史差异，下次视觉修订统一；本轮不修改原型或配色 Token。

- 正式产品自动保存私人修改，点击「更新发布」才更新公开版本；现有原型仍把已发布记录的保存视为线上更新，后续需同步修改。

- 正式编辑器提供文件、HTML 展示块和外部链接嵌入入口。原型尚未实现这些展示块；具体产品行为见 PRD。

## 产品体验

Studio 是所有者的私人工作室。首页呈现最近保存的思考与经历，快速记录、搜索和知识目录提供随时可达的入口。思考脉络用于回看跨时间的记录，知识空间用于按目录组织内容。这些视角可以引用同一份记录。

| 任务 | 路径 |
| --- | --- |
| 随手记录 | 首页「记录此刻」→ 填写正文或添加附件 → 自动保存并出现在全部记录 → 按需补充属性 |
| 写一篇笔记 | 知识空间 → 进入空间或分类 → 新建笔记 → 编辑标题和正文 → 自动保存并显示状态 |
| 找回内容 | 搜索 → 输入关键词或设置筛选 → 进入原文 |
| 回看一条思考 | 思考脉络 → 创建或打开主题 → 加入已有记录 → 按时间回看 → 打开原文 |
| 导入、整理与备份 | 导入中心 → 查看结果与原文 → 在全部记录中按需整理；备份通过设置中的数据管理操作 |
| 删除与恢复 | 编辑页或列表移入回收站 → 恢复或确认永久删除 |

## 导航与布局参考

桌面采用固定左栏与可滚动主区。正式导航覆盖品牌、搜索、新建记录、首页、全部记录、知识空间、思考脉络、导入中心、空间分类树、设置与回收站，具体顺序在实屏设计时核定。顶部显示 Studio、当前路径及语言按钮。空间树展开状态保存在当前会话。

| 屏宽 | 布局参考 |
| --- | --- |
| 大于 1250px | 252px 左栏。主内容按页面使用阅读列、列表或网格。 |
| 701–1250px | 240px 左栏。1050px 及以下空间和导入网格、空间详情布局改为单列，编辑属性栏收窄。 |
| 700px 及以下 | 导航覆盖首页、搜索、全部记录和其他功能，具体底栏与抽屉布局在实屏设计时确定。内容预留安全区，编辑属性置于正文下方。旧原型的收集箱底栏待替换。 |

首页按内容自然滚动，快记展开时其他内容继续可访问。移动端验收重点是浏览、搜索、快记、底栏切换和返回，特别检查软键盘打开时的操作和底部安全区。

| [账户设置](../../prototypes/studio/settings.html) | 所有者账号、显示名称和角色，提供修改密码和退出登录。设置区另有外观与数据管理页签。 |
| [外观](../../prototypes/studio/appearance.html) | 暖白与清白底色、灰紫等强调色预设、预览和恢复默认。偏好保存在当前浏览器。 |
| [数据管理](../../prototypes/studio/data.html) | 多选导出 Markdown，可附带 YAML 元数据。可生成 JSON 备份、查看清单、校验并确认恢复。恢复面向空白工作区。附带演示和清理工具，原型备份中的附件仅为元数据，正式完整备份须包含必要文件、人工脉络及成员关系。 |

## 控件、状态与反馈

- 主按钮用于保存、登录、确认等主要操作。次要动作使用描边或文本按钮，危险动作用独立色及确认对话框。搜索结果、卡片和关联节点保持可点击。
- 内容类型选择器用自定义浮层，选中项有对勾。支持方向键、回车、Esc 和点击外部关闭。搜索与属性表单仍有原生选择器。
- 原型用提示条、行内错误、弹窗及通知反馈结果。保存显示待保存、保存中、成功和失败状态。离开有未保存修改的页面时提示确认。删除、恢复和导入分别反馈操作结果。
- 快记支持 Ctrl/⌘＋Enter，完整编辑器支持 Ctrl/⌘＋S，共享壳支持 Ctrl/⌘＋K 搜索。主要操作须有可见键盘焦点，图标按钮须有名称。
- 最近记录仅当前卡片悬停时上移 2px，显示边框和轻微阴影。减少动态效果时保留静态反馈。
- 可视化模式在原型中从 CDN 加载 Tiptap，将正文保存为 Markdown。加载失败时可继续使用 Markdown。旧内容不能无损转换时使用 Markdown 源码模式。关联选择器目前位于源码模式。

## Studio 设计系统

现有原型默认主题为「暖白底色＋灰紫强调色」，不代表新的清冷主题已经实现。清白为可选底色，靛蓝、松绿和石墨为可选强调色，不替代默认组合。色值、尺寸与动效可以在实屏评审后调整。实际运行的原型样式见 [共享 CSS](../../prototypes/studio/assets/css/studio.css)。

### 1. 品牌与设计理念

主题名为「暖白 · Studio」。气质安静、清晰、克制，以暖白阅读面、暖灰导航和深灰文字组织信息。用少量灰紫标出当前选中项、主要操作与键盘焦点。首页优先让用户读到自己的记录，长文编辑留出连续的阅读空间。

### 2. 色彩系统

| Token | HEX | 用途 |
| --- | --- | --- |
| `surface` | `#FCFAF8` | 主工作区暖白底 |
| `surface-dim` | `#EEEAE7` | 侧栏、底栏与次级导航区域 |
| `surface-container-lowest` | `#FFFFFF` | 菜单、弹窗及需要区分的卡片 |
| `surface-container-low` | `#F3EFEC` | 悬停背景和辅助区域 |
| `surface-container-high` | `#E7E1DE` | 禁用控件背景与骨架 |
| `primary` | `#795D8C` | 主按钮、链接、键盘焦点 |
| `primary-hover` | `#684F79` | 主按钮悬停背景 |
| `primary-container` | `#EEE7F1` | 导航选中底、选中菜单项 |
| `on-primary` | `#FFFFFF` | 主按钮文字与图标 |
| `on-primary-container` | `#624873` | 选中项文字与图标 |
| `text-primary` | `#252126` | 标题与正文 |
| `text-secondary` | `#666069` | 摘要、日期、辅助说明 |
| `text-tertiary` | `#726A74` | 占位符、快捷键和次级元数据 |
| `border-subtle` | `#DCD6D5` | 分隔线及卡片轻边框 |

| 状态 | 前景 | 背景 | 用途 |
| --- | --- | --- | --- |
| `success` | `#246348` | `#E5F3EC` | 已保存、导入成功 |
| `warning` | `#815314` | `#FFF2D8` | 待整理、部分成功、需要留意 |

状态同时显示文字或图标。浅色分隔线用于分组，需要凭边框辨认的输入框使用较深轮廓。

基础底色、正文色与默认强调色取自现有原型变量；其余交互色值为设计建议，仍需实屏核验。外观设置保留两种底色与四种强调色的独立组合，偏好保存和作用范围见 PRD 的 Studio 外观设置。

### 3. 文字排版

界面使用系统无衬线字体，中文回退可用 PingFang SC、Microsoft YaHei。代码使用 ui-monospace、SFMono-Regular、Consolas 或系统等宽字体。

| 层级 | 字号 | 行高 | 字重 | 场景 |
| --- | --- | --- | --- | --- |
| `display` | 28–32px | 1.25 | 600 | 首页、思考脉络主题 |
| `h1` | 22–24px | 1.3 | 600 | 笔记、知识空间标题 |
| `h2` | 18–20px | 1.4 | 600 | 页面区块标题 |
| `record-title` | 17px | 1.5 | 600 | 最近记录标题 |
| `body-lg` | 16px | 1.75 | 400 | 正文、编辑区 |
| `body-md` | 14px | 1.5 | 400–500 | 主导航、表单、摘要 |
| `caption` | 12–13px | 1.4 | 400–500 | 日期、标签、状态与子分类 |

### 4. 间距与布局

以 4px 为基准。常用间距为 4、8、12、16、24、32 和 48px，分别用于紧邻元素、图标与文字、控件内距、列表与卡片、面板及章节。桌面左侧目录延续 252px、较窄桌面 240px 的参考值，主导航以 36px 行高起步。移动端底栏适配安全区，主要触控目标建议至少 44px。

首页按页头、快记、最近记录的顺序展示，按内容自然滚动。宽屏最近记录三列，中等宽度双列，窄屏单列。编辑页先保障正文宽度，再安排属性与关联。

### 5. 圆角与阴影

小标签和快捷键用 4px 圆角，按钮、输入与下拉菜单用 8px，卡片和对话框用 12px。头像及药丸标签可用全圆角。普通卡片靠细边框划分，浮层用阴影表明层级。

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `shadow-sm` | `0 1px 2px rgba(37, 33, 38, .06)` | 需要轻微层次的卡片 |
| `shadow-hover` | `0 4px 12px rgba(121, 93, 140, .12)` | 当前悬停的可点卡片 |
| `shadow-dropdown` | `0 8px 24px rgba(37, 33, 38, .16)` | 菜单、搜索浮层 |

### 6. 组件样式

| 组件 | 默认与尺寸 | 交互状态 |
| --- | --- | --- |
| 主按钮 | 灰紫底、白字。桌面参考高 36px、圆角 8px。 | 悬停加深，提交中保留动作反馈，禁用状态保留可辨识文字。 |
| 次要按钮与输入 | 透明或白底，轮廓与页面分组相协调。常规输入参考高 40px，同排控件对齐。 | 悬停加底色。错误用边框和行内文字共同标记。 |
| 导航与选择器 | 默认低对比背景，当前页用淡灰紫底和深灰紫字。 | 下拉选中项保留对勾。悬停与选中应能区分。 |
| 记录卡片 | 标题、摘要、时间优先。卡片可用暖白或纯白底。 | 可选轻微上移 2px，附近卡片保持静止。启用减少动态效果时保留静态反馈。 |
| 键盘焦点 | 参考 2px 灰紫外描边，外扩 2px。 | 焦点在菜单、卡片和表单内保持清晰。 |
| 弹窗与反馈 | 使用统一标题、正文和操作区。 | 保存、失败及删除等结果有明确文字。确认按钮说明动作及影响。 |

## 多语言与内容来源

正式界面支持简体中文与英文，覆盖导航、表单、状态、空态、错误和确认提示。切换保留当前页面和输入，偏好在当前浏览器保存；用户内容、空间名、主题、标签和引用保留原文。原型只有部分文案完成翻译，当前通过刷新切换，后续需补齐。移动端覆盖阅读、搜索、快记、基础编辑和人工脉络回看。

记录类型和目录标签由用户按需填写，记录保存与公开发布分别操作。来源可来自手动记录、文件、网页或 AI 对话。导入默认私有，发布与撤回是独立操作。原型公开预览用于验证文案和操作边界，Site 公开站目前没有现行页面。

## 原型边界与后续设计

- 原型数据和演示认证依赖浏览器存储。备份恢复、文件导入、发布状态只体现原型能力。正式认证、附件存储和公网访问需另行实现。
- 思考脉络示例用于验证「梳理 → 引用 → 关联图 → 时间线」。主题创建、候选关联确认、长期记忆与版本比较尚未实现。
- 后续沿用自由记录、AI 提出候选、用户确认的方式。梳理保留证据与历史。新版确认后成为当前解释，原始记录保留。具体阶段和权限规则见 [PRD](../product/PRD.md)。
- 待实屏核验桌面及手机宽度、英语长文案、触控与键盘导航、Tiptap 联网及降级、快记保存、打开原文和恢复数据。
