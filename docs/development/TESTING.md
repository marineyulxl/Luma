各功能只记录核心验收场景，自动化细节保留在测试代码中。测试命令见 [开发指南](DEVELOPMENT.md#测试与代码检查)。

## 登录

| 操作 | 预期结果 |
| --- | --- |
| 输入正确账号密码 | 登录成功，能读取当前用户资料 |
| 输入错误密码 | 登录失败，显示统一错误提示 |
| Access Token 到期后使用有效刷新凭据 | 获取新令牌，继续访问 |
| 退出后继续访问 | 会话失效，需要重新登录 |
| 会话过期后尝试刷新 | 刷新失败，需要重新登录 |

自动化测试：[test_auth.py](../../backend/tests/test_auth.py)。上述接口场景已有自动化覆盖，页面验收待前端完成。
